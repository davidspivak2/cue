# Subtitle fonts

Font files (`.ttf`, `.otf`) in this directory are registered with Qt at runtime so subtitle preview and overlay use the curated fonts (Heebo, Assistant, Rubik, IBM Plex Sans Hebrew, Noto Sans Hebrew, Playpen Sans Hebrew, Alef, Arimo, Baloo 2, Fredoka, Fredoka One Hebrew, Lilita One, Luckiest Guy, Secular One, Suez One, Titan One, Frank Ruhl Libre). Most are sourced from [Google Fonts](https://fonts.google.com/) (OFL/Apache-2.0); `Fredoka One Hebrew` is bundled from the [hafontia-zz/Fredoka-One](https://github.com/hafontia-zz/Fredoka-One) repository under OFL-1.1.
